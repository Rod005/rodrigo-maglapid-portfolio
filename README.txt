RODRIGO PORTFOLIO WEBSITE 

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.

CONTACT FORM
- All form inquiries are sent to support@abotrix.com through FormSubmit.
- On the very first test submission, FormSubmit sends an activation email to support@abotrix.com.
- Open that email and click Activate Form.
- After activation, future inquiries arrive automatically.
- Check Spam/Junk if the activation message does not appear in Inbox.

IMPORTANT
- The form will work properly after the website is deployed online.
- Do not test only from a local file if your browser blocks external form submissions.
- No email password is stored in the website.

HOW TO EDIT
- Text and sections: index.html
- Colours and layout: styles.css
- Menu and animations: script.js

DEPLOYMENT
Upload the folder to Vercel, Netlify, GitHub Pages, or your ABOTRIX server.
Suggested address: portfolio.abotrix.com
